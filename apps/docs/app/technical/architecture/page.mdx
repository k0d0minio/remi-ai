# Architecture

## Structure du dépôt

```text
apps/
  web/        l'application produit - surface connectee (:3000)
  marketing/  le site public - sans authentification, indexable (:3001)
  admin/      operations internes - operateur uniquement (:3002)
  docs/       ce site - Nextra (:3003)
packages/
  ui/         @remi/ui - le design system, seul foyer des primitives
  services/   @remi/services - stockage, e-mail, IA, env ; des points de jonction fournisseur, pas des integrations
.icm/         la couche de travail - intake, docs et pipeline de livraison
```

La flèche de dépendance ne pointe jamais que **application → package**. Un package qui importe une application est une
erreur de lint, et il n’existe aucun import d’application à application : tout ce dont deux applications ont besoin vit dans `packages/`.

## Pile technologique

| Couche       | Choix                                           |
| ------------ | ----------------------------------------------- |
| Monorepo     | Turborepo 2, pnpm 10 workspaces, Node 22        |
| Framework    | Next.js 16, App Router, React 19                |
| Langage      | TypeScript 5 — strict partout                   |
| Styles       | Tailwind CSS 4, tokens dans `@remi/ui/tokens.css` |
| Primitives   | shadcn/ui (New York) sur Radix                  |
| Docs         | Nextra 4                                        |
| Packages     | tsup → ESM                                      |
| Hébergement  | Vercel — un projet par application              |

Le stockage, l’authentification, l’e-mail et l’IA ne figurent **pas** dans ce tableau, volontairement : `@remi/services` définit les
points de jonction et aucun fournisseur n’est encore retenu. Voir la page Packages.

## Trajet d’une requête

Une page de `apps/web` s’affiche comme composant serveur, appelle un service via
`@remi/services/server`, et affiche des primitives de `@remi/ui`. Le chemin d’import est l’énoncé
de l’endroit où le code s’exécute — `/shared` est isomorphe, `/server` ne tourne que sous Node — si bien qu’un bundle client
ne peut jamais acquérir par accident un pilote de base de données.
