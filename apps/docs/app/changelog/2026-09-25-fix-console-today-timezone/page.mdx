# Today means Brussels, not the server

_25 September 2026_

Between midnight and one or two in the morning, the patient page and the new consultation screen
used to open on yesterday's date — the meal form, the observation, the goal check-in, the recipe
you assign, the consultation itself. They read the server's clock, and the server runs on UTC, an
hour or two behind Brussels. You could always see the date and correct it, but you shouldn't have
had to.

They now read the same clock your patients' own entries use: today, in Belgium, whatever time zone
the server happens to run in.
