# Changelog

What shipped, in the user's voice. One page per shipped feature, added by the pipeline's Release stage
(or a bug or tweak lane, when the change is user-visible) in the same PR as the change itself — committing the entry **is** the publish, so the changelog can
never be more than one merge out of date.

Entries live at `changelog/<YYYY-MM-DD>-<slug>/`, newest first.
