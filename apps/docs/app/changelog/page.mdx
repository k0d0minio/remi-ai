# Changelog

What shipped, in the user's voice. One page per shipped feature, added by the pipeline's Ship stage
in the same PR as the change itself — committing the entry **is** the publish, so the changelog can
never be more than one merge out of date.

Entries live at `changelog/<YYYY-MM-DD>-<slug>/`, newest first.
