# Initiatives

The strategy the current work ladders up to, and what this quarter is measured against. Scope and
Define read this page for the why-now; Ship quotes an objective from it, verbatim, in the ship note.

## Current initiative

**The founding pilot cohort, and the ecosystem it lands in.** REMI is pre-launch: nothing is sold as
live, no customer data is processed, and there is no traction to report. What this period is trying
to move is one question — will the founding cohort keep REMI once it stops being free — and the
horizon is the enrolment window.

The cohort is small on purpose and involved on purpose: a capped number of practitioners, each
application reviewed personally, shaping what gets built rather than testing what has been. It is
co-designed with functional medicine through a signed clinical partnership. Nothing about the cohort
is a mailing list, and nothing built for it is announced before it works.

> **The pilot's commercial terms are not published here.** The cohort ceiling, the enrolment window,
> the price and the billing date are a signed agreement, and they live in exactly one place: the
> operator console, which renders them rather than editing them. This site is publicly viewable, so
> it carries the shape of the pilot and not its figures — and the partner clinic is described rather
> than named for the same reason. A spec that needs a number takes it from the console.

## Objectives this quarter

| Objective                                                      | Measure                                                                                      | Where it stands                                                             |
| -------------------------------------------------------------- | -------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| An ecosystem that looks and feels credible end to end          | An entry screen on every surface, one brand, a public help centre                            | Entry screens in place; brand foundation shipped; one help-centre page live |
| The cohort enrolled before the window closes                   | Every place filled inside the enrolment window                                               | Window open; applications tracked in the console, no count published here   |
| The core loop, end to end, for one practitioner and one person | Recommendations become a plan; the plan becomes meals and steps; progress comes back         | Both surfaces built, on fixture data — nothing persists yet                 |
| The data question answered before the first record exists      | Trust posture published, residency intent written down, processors named before they process | Trust page live; storage, email and AI still uncommitted seams              |

Where each of those actually stands, in more words than a cell holds:

- **The ecosystem.** Web, admin, marketing, support and the demo sandbox each have a front door a
  stranger can land on. The brand foundation landed on 3 August 2026 and put one wordmark, one icon
  and one tagline across every app; this site's navbar was its last plain-text holdout. The help
  centre is live with a single page — its article routes are written as structured content and not
  yet routed.
- **The cohort.** The enrolment window is open. Applications are tracked in the operator console,
  which still renders fixture data, so no number appears here until it is a real one.
- **The core loop.** The practitioner's practice, clients and therapeutic frame are built, as are
  the person's today, meals, steps and plan. Every screen reads fixture data through the query
  layer: registering a database replaces the body of each query and moves no caller.
- **The data question.** The trust page is live on the public site. Storage, email and AI are still
  seams in `@remi/services` with no vendor committed — which is exactly what keeps data residency a
  selection criterion rather than a migration project.

## What this page does not claim

No users outside the pilot, no results, no revenue. The three statistics on the public site are WHO
figures describing the problem REMI addresses, not outcomes REMI has produced, and this page holds
to the same rule: a number that cannot be sourced does not appear here, and fixture data is not
evidence.
