# CIQUAL — source and licence

`ciqual-subset.json` is a derived subset of the French food-composition table, redistributed here
under the terms below. It exists so the service tests run against real data; it is generated by
`pnpm ciqual:fixture <dir>` from the full export and is never edited by hand.

|              |                                                                                                                                     |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------- |
| Table        | Table de composition nutritionnelle des aliments **Ciqual 2025**                                                                    |
| Publisher    | ANSES — Agence nationale de sécurité sanitaire de l'alimentation, de l'environnement et du travail, unité Observatoire des Aliments |
| Authors      | Du Chaffaut, Laure; Oseredczuk, Marine; Gauvreau-Béziat, Julie                                                                      |

## Attribution

The Etalab licence grants the right to reproduce, adapt and redistribute this data, including
commercially, on one condition: the source must be named. Every surface that shows a CIQUAL number
carries it — the console's home line, the `/aliments` page — and the citation of record is:

> Du Chaffaut, Laure; Oseredczuk, Marine; Gauvreau-Béziat, Julie, 2025, « Table de composition
> nutritionnelle des aliments Ciqual 2025 », <https://doi.org/10.57745/RDMHWY>, Recherche Data Gouv,
> V1.

The licence text is at <https://www.etalab.gouv.fr/licence-ouverte-open-licence/>.

## What is not here

The full export — five XML files, 75 MB — is deliberately not committed. `pnpm ciqual:import <dir>`
takes the unpacked export from wherever the operator downloaded it.
