REMI fonctionne selon une approche Lean Startup centrée utilisateur, avec une logique de co-construction terrain.

Principes de travail :

Construire rapidement des versions simples mais fonctionnelles (MVP)

Tester rapidement avec de vrais praticiens

Mesurer les usages réels plutôt que les suppositions

Prioriser uniquement les fonctionnalités à forte valeur utilisateur

Itérer en continu via des cycles courts

Méthodologie utilisée :

Build → Measure → Learn

Priorisation par impact utilisateur vs difficulté technique

Décisions prises sur :

données terrain

feedback utilisateurs

métriques d’usage

cohérence avec la vision REMI

Méthode de prise de décision :

Les fonctionnalités ne sont pas développées “par intuition”

Chaque évolution doit répondre :

à un problème réel identifié

à une fréquence d’usage potentielle

à un impact concret pour le praticien

Priorité aux “quick wins” :

haute valeur

faible complexité technique

Organisation produit :

Cycles d’itération toutes les 2 semaines

Validation continue avec les praticiens

Focus sur :

adhérence patient

gain de temps praticien

simplicité d’utilisation

adoption rapide
