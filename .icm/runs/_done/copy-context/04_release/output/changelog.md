# The patient's context, ready to paste

_17 September 2026_

Generating a recipe with an AI model meant retyping a patient's profile, their constraints and
your protocol into a chat window by hand, once per recipe, from a console that already held all of
it. The patient's working view now carries a « Copier le contexte » card: one click puts the whole
context on your clipboard as plain French text.

What you will notice:

- The text opens with a short preamble in your words — « tu es un chef de cuisine qui respecte les
  recommandations d'une nutrithérapeute … » — and you can rewrite it before copying. It starts
  fresh each time you open the page.
- A checkbox per block, so you decide what goes: profile, objectives, the current instruction,
  recommendations, supplements, essentials. The living summary is there too, unticked by default —
  it is the longest part and a recipe rarely needs it.
- Only the pseudonym travels. The real name, the email and the patient link are never in the
  text, whichever blocks you include.
- The assembled text stays visible and selectable underneath, so you can select it by hand if
  your browser refuses the copy.
- Each copy is recorded in the journal of actions, with the patient and the blocks that went.

REMI still calls no model itself. This is the paste you were already making, made in one gesture —
and the part of it that assembles the context is the same piece the AI features will use when they
arrive.
