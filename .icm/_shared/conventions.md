# Conventions (Layer 3 reference) — redirect

The code rules are canonical in **[`/CONVENTIONS.md`](../../CONVENTIONS.md)** at the repo root. They
live there once; this file does not copy them, because two copies of a rule is how a rule starts
disagreeing with itself.

The Build stage loads `/CONVENTIONS.md` directly — read it for code style, design-system rules,
leanness rules, environment-variable handling, and git. For subtree-scoped deltas, also read the
relevant `apps/*/AGENTS.md` or `packages/*/AGENTS.md`.
