# Build notes: supplement-protocol

- commits: `feat: supplement-protocol — table, service, migration, audit vocabulary`,
  `feat: supplement-protocol — protocol card, add form, category overlap, profile relabel`
- demo: none (spec `demo: none` — built against the real stack)

## What changed

### packages/services (data layer + seam)

- `db/schema.ts`: new `patient_supplements` table — `name` (required), `dose` / `timing` /
  `reason` (`not null default ''`), `position` (`integer not null default 0`), `archivedAt`
  (nullable), patient FK `onDelete: cascade`, shared timestamps. No `started_on` — created-at is
  enough (Decision 2).
- `db/migrations/0009_salty_terror.sql` + `meta/0009_snapshot.json` + `_journal.json`: generated by
  `pnpm db:generate`. Pure `CREATE TABLE` + FK — additive, applies over existing rows with no
  intervention.
- `db/models/patient-supplement.ts`: `PatientSupplement`, `PatientRecommendation` shape minus the
  category; exported from the models barrel and re-exported through `shared`.
- `db/services/patient-supplements/`: the service behind the seam — list / listArchived / add /
  update / move / archive(toggle) / delete, ordered by `position` then created-at, appending at the
  next position; `name` validated non-empty; every write calls `touchPatient`. Tested against the
  in-memory client (`index.test.ts`, 9 cases).
- `shared/audit.ts`: `supplement.added/.updated/.archived/.restored/.deleted/.reordered`.
- `db/index.ts` + `server/index.ts`: service exports (+ `SupplementInput`).

### apps/admin (the console)

- `lib/patients/actions.ts`: `add/update/move/archive/delete` supplement server actions, each
  re-asserting the operator and (except the silent reorder, mirroring recommendations) writing the
  matching audit entry.
- `components/patients/supplement-protocol.tsx` / `supplement-item.tsx` / `supplement-add-form.tsx`:
  the protocol card — active rows as a compact table (name · dose · timing · reason), inline
  add / edit / archive / reorder, archived rows behind a `<details>` fold. Same component renders
  both tables; archived rows drop the reorder controls.
- `components/patients/vocabulary.ts`: `addableRecommendationCategories` = `recommendationCategories`
  without `supplement`.
- `components/patients/recommendation-add-form.tsx`: the category Select maps
  `addableRecommendationCategories`. `recommendationCategories`, `categoryLabels["supplement"]`, the
  service enum and `RecommendationGroups` are untouched — existing rows still validate, group,
  render, and stay re-categorisable from the edit form.
- `components/patients/patient-form.tsx`: the `supplements` profile field relabelled to
  "Compléments déjà pris, hors protocole" with a hint. Column name / type / content unchanged.
- `app/(admin)/patients/[id]/page.tsx`: loads the two supplement lists and renders the card after
  the recommendations; the delete card's cascade list gains the protocol.
